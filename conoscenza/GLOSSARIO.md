# Glossario — spiegazioni in parole semplici

A cura della chat **INSEGNANTE**. Ogni volta che emerge un concetto che supera la
comprensione attuale, aggiungi qui una voce.

**Formato di ogni voce:**

```
## Termine
Spiegazione breve, in parole semplici. Poi un'analogia concreta della vita reale.
```

---

## Git
Un "fotografo" dei file. Ogni volta che glielo chiedi, scatta una foto di tutti i
file del progetto e la conserva. Puoi tornare a una foto precedente se rompi qualcosa.
*Analogia:* come i punti di salvataggio di un videogioco, ma per i file.

## Commit
Una singola "foto" scattata da Git, con una data e un messaggio che spiega cosa è
cambiato. *Analogia:* una tappa numerata di un percorso.

## Repository
La cartella del progetto "gestita" da Git, con dentro tutta la sua cronologia di
commit. *Analogia:* un album che raccoglie tutte le foto, non solo l'ultima.

## GitHub
Un sito web dove si copia il repository, così esiste anche online e non solo sul PC.
*Analogia:* il "cloud" delle foto, ma per il codice.

## git push
Il comando che "spinge" le foto dal PC a GitHub. *Analogia:* caricare le foto
dall'album di casa all'album online.

## GitHub Pages
Il servizio gratuito di GitHub che prende i file di un repository e li mostra come
un sito web vero, con un indirizzo pubblico. *Analogia:* l'album online diventa
una vetrina visibile a tutti.

## HTML / CSS / JavaScript
Le tre "materie prime" di una pagina web:
- **HTML** = la struttura (i mattoni: titoli, testi, immagini, modulo).
- **CSS** = l'aspetto (trucco e vestiti: colori, font, spazi).
- **JavaScript** = il comportamento (i movimenti: il carosello che scorre, l'invio del modulo).
*Analogia:* HTML è lo scheletro, CSS è il vestito, JavaScript è il movimento.

## Web3Forms
Un servizio esterno gratuito che riceve i dati compilati in un modulo e li inoltra
per email. Serve perché una pagina statica, da sola, non può spedire email.
*Analogia:* un postino assunto per portare i moduli a destinazione.

## Segnaposto (class="ph")
Un testo finto, evidenziato in giallo nella pagina, che indica "qui va scritto il
dato vero". Finché se ne vedono, il sito non è personalizzato.
